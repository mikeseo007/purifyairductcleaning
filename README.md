# Purify Air Duct Cleaning — Website

SEO-focused marketing site for [Purify Air Duct Cleaning](https://purifyairductcleaning.com/), based at 20533 Biscayne Blvd #8, Aventura, FL 33180. The company serves northern Miami-Dade, Broward and Boca Raton.

Phone: (305) 330-1328 · Email: office@purifyairductcleaning.com · Open 24 hours, every day.

## Stack

- [Astro](https://astro.build) — static HTML, fast loads, strong SEO
- Tailwind CSS v4
- `astro:assets` for responsive WebP images
- `@astrojs/sitemap` for `sitemap-index.xml`
- Netlify hosting and Netlify Forms for service requests

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Netlify builds with `npm run build` and publishes `dist/` (see `netlify.toml`).

Service pages (`src/data/services.ts`) and city pages (`locations` in `src/data/site.ts` plus `src/data/location-content.ts`) are generated by `src/pages/[slug].astro`. To add a city, add it to `locations` and write its copy in `location-content.ts`.

## Editing content

- `src/data/site.ts` — name, address, phone, email, hours, cities, map embed and Google rating. When you have verbatim Google reviews, paste them into `reviews`.
- `src/data/services.ts` — service copy, FAQs and related links
- `src/data/location-content.ts` — homepage and city page copy
- `src/content/blog/*.md` — blog posts
- `src/assets/images/` — photos. `scripts/optimize-images.mjs` converts them to WebP before dev and build.

The public rating of 5.0 from 79 reviews is taken from published business listings. Individual review text is left empty until the Google reviews are copied word for word.

## SEO

- Unique title, meta description, H1 and canonical URL on every page
- JSON-LD: `HVACBusiness`, `WebSite`, `Service`, `FAQPage`, `BreadcrumbList`, `BlogPosting`
- Open Graph cards, XML sitemap, `robots.txt`

## Service request form

The form posts to Netlify Forms (`service-request`) and redirects to `/thank-you/`. After the first deploy, enable email notifications in Netlify under **Site configuration → Forms → Form notifications** and send them to office@purifyairductcleaning.com.
